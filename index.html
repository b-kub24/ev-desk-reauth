1. Log in to Schwab
Opens in a new tab. Log in, approve the app, and you land on a blank page whose address starts with https://127.0.0.1/?code=. Copy that whole address (tap the address bar, Select All, Copy), then come back to this tab.
The code Schwab hands you lasts about 30 seconds, so paste and submit right after copying. If it says the code expired, just tap Log in to Schwab again.
